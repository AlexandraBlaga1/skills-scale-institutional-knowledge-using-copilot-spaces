# OctoAcme Role Clarity Checklist

Use this checklist at the start of a project or when a new workstream begins to make ownership, collaboration, and escalation paths explicit.

## Ownership
- [ ] Each workstream has a named accountable owner
- [ ] Delivery, product, engineering, QA, and support responsibilities are clearly assigned
- [ ] Decision rights are documented for scope, quality, timing, and customer-impacting issues

## Collaboration
- [ ] Cross-functional handoffs are described for planning, execution, testing, and release
- [ ] Dependencies and communication owners are identified for each milestone
- [ ] The team agrees on how status updates will be shared and reviewed

## Escalation and support
- [ ] Blockers can be raised through a defined path
- [ ] Customer or support issues have a named owner for triage and follow-up
- [ ] Release readiness and rollback decisions are assigned to the appropriate roles

## Review
- [ ] The checklist is reviewed during kickoff and updated as the team changes
- [ ] The checklist is referenced during regular delivery and retrospective discussions
